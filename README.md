
# MERN Stack Development Coursework

## Overview

This repository contains the practical work and coursework completed as part of the MERN Stack Development curriculum. It focuses on full-stack web development using MongoDB, Express.js, React.js, and Node.js, along with hands-on exploration of NoSQL database technologies.

## Technologies Used

- **MongoDB** – NoSQL document database
- **Express.js** – Backend web application framework
- **React.js** – Frontend JavaScript library
- **Node.js** – JavaScript runtime environment
- **HTML, CSS, and JavaScript** – Web development fundamentals

## Description

The coursework provides practical knowledge of modern web application development, including frontend interface design, server-side programming, REST API development, and database integration. It explores CRUD operations, HTTP request handling, client-server communication, and data management using MongoDB.

The coursework also introduces different NoSQL database models through CouchDB, Apache Cassandra, and Redis, helping develop an understanding of document storage, distributed data management, key-value operations, and caching concepts.

## Learning Outcomes

- Understand the architecture of MERN stack applications.
- Develop interactive user interfaces using React.js.
- Build backend services and REST APIs using Node.js and Express.js.
- Perform database operations using MongoDB.
- Understand different NoSQL database models and their applications.
- Integrate frontend, backend, and database components.
- Gain practical experience with modern web development tools and technologies.

## Conclusion

This coursework builds a foundation in full-stack web development and NoSQL database management. It strengthens programming skills and provides an understanding of how modern web applications are designed, developed, and connected to databases.
